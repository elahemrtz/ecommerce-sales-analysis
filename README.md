# E-Commerce Sales Analysis

Exploratory data analysis of 1,000 e-commerce products across 7 categories,
using 12 months of synthetic sales data.

**Source:** [Kaggle — E-Commerce Sales Analysis](https://www.kaggle.com/datasets/fahmidachowdhury/e-commerce-sales-analysis)

## Business Questions
- Which categories drive the most revenue and units?
- Is there a relationship between price and sales volume?
- Do Customer ratings correlate with sales?
- Does the catalog show seasonal patterns across the 12-month period?
- How Concentrated is revenue?

## Tools
Python, pandas, matplotlib, seaborn, Jupyter

## Project Structure
- `data/` — raw dataset
- `notebooks/` — analysis notebooks
- `images/` — exported charts
